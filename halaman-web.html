Halaman web

Laman web atau halaman web (bahasa Inggris: web page) atau adalah halaman utama dari suatu situs web yang diakses oleh pengguna pada awal masuk ke situs tersebut. Sebagai contoh, jika seseorang mengetik alamat internet http://id.wikipedia.org, mereka akan diarahkan langsung ke halaman utama dari alamat tersebut. Vermaat di sisi lain mengartikan laman web sebagai setiap dokumen elektronik dalam web yang dapat menyimpan teks, gambar, audio, dan video. Selain itu, laman web biasanya tersambung ke dokumen-dokumen lainnya. Sebagian besar dari laman web tersebut memuat data-data yang tidak berstruktur dan berantakan.

Menurut Sanna, sebuah laman web biasanya dibangun atas banyak halaman web yang saling berhubungan. Hubungan antara satu laman web dengan laman lainnya disebut dengan pranala (atau hyperlink), sedangkan teks yang dijadikan sebagai media penghubung disebut dengan hieperteks. Prasetio menambahkan bahwa proses tampilnya suatu laman web di peramban melibatkan Hypertext Markup Language (HTML), yaitu bahasa markah yang digunakan untuk merancang suatu laman web, sedangkan aksesnya biasa menggunakan Hypertext Transfer Protocol (HTTP), yaitu protokol untuk mengatur komunikasi antara kelayan dan peladen.

Agustina dalam penelitiannya menguraikan bagian-bagian dari laman web menjadi tujuh, yaitu title (judul), icon (favicon), URL (alamat web) atau path dan nama dokumen web, header (bagian atas), left menu (menu kiri), footer (bagian kaki), dan content (bagian utama). Mayoritas instansi atau perusahaan saat ini membangun laman web dengan tujuan untuk mempromosikan produknya.
